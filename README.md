# Лабораторная работа 3 — «Лотерея»

## Назначение

Консольная игра на Python 3, в которой игрок покупает лотерейные билеты с ограниченного баланса и проверяет их на выигрыш. В этой версии логика разделена на функции, данные и операции над билетами вынесены в отдельный модуль, а вместо случайных событий работают случайные подсказки.

## Состав проекта

- `main.py` — запуск игры, обработка команд и игровой цикл.
- `lotereya_data.py` — цена билетов, выигрышные номера, подсказки и функции работы с билетами.
- `requirements.txt` — список сторонних зависимостей проекта.
- `docs/lab2.docx` — отчёт по лабораторной работе 2.
- `docs/lab3.docx` — отчёт по лабораторной работе 3.

## Команды

- `help` — показать список команд;
- `buy {количество}` — купить билеты (от 1 до 1000 за раз);
- `draw {номер билета}` — проверить, выигрышный ли билет;
- `tip` — получить случайную подсказку;
- `report` — показать баланс, купленные билеты и результаты обработок списка;
- `exit` — завершить игру.

Ввод обрабатывается без учёта регистра и лишних пробелов. Если команда или значение некорректны, программа сообщает об этом и продолжает работу.

## Устройство программы

В `main.py` глобальные переменные хранят список купленных билетов и баланс, который изначально равен 100. Игровой цикл `while True` читает команду, разбирает её через `split()` и передаёт нужные данные функциям модуля `lotereya_data`. При покупке стоимость списывается с баланса только если средств хватает; при выигрыше сумма приза добавляется к балансу, а номер попадает в множество выигрышных билетов.

В `lotereya_data.py` цена билета задана константой `ticket_price`, выигрышные номера и размеры призов хранятся в словаре `wins`, а уже отмеченные выигрыши — в множестве `wins_set`. Функция `buy(tickets, qty)` добавляет в список билеты с порядковыми номерами через `extend(range(...))`. Функция `draw(tickets, wins, number)` возвращает `True`, если номер есть и среди билетов, и среди выигрышных, иначе `False`. Функция `add_win(wins_set, n)` дополняет множество, а `even_tickets(tickets)` и `plus_one(tickets)` построены на генераторах списков: первая оставляет чётные номера, вторая возвращает номера со сдвигом на единицу.

Функция `random_tip()` выбирает одну из трёх подсказок с помощью `random.choice()`. Подсказки носят шуточный характер и не влияют ни на баланс, ни на номера билетов. Внешние библиотеки не требуются: `random` входит в стандартную библиотеку Python.

В конце `lotereya_data.py` оставлен закомментированный блок проверок `test_buy`, `test_draw`, `test_add_win`, `test_even_tickets` и `test_plus_one`, который можно раскомментировать для быстрой самопроверки функций.

## Запуск

Откройте проект в PyCharm и запустите `main.py`.

Пример маршрута к выигрышу: `buy 20` → `draw 7` → `report`.
